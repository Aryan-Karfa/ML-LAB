# 🧠 Machine Learning Lab

Welcome to my **Machine Learning Lab** — a practical workspace for exploring, implementing, and experimenting with core concepts of **Machine Learning and Artificial Intelligence**.

This repository contains my lab programs, experiments, implementations, datasets, and supporting resources developed throughout the ML coursework.

The goal of this lab is to move beyond theoretical concepts and **implement machine learning techniques through hands-on experimentation**.

The repository focuses on:

* 📊 Data preprocessing & analysis
* 🧹 Data cleaning and feature engineering
* 📈 Exploratory Data Analysis (EDA)
* 🧠 Supervised Learning
* 🔍 Unsupervised Learning
* 📐 Regression & Classification
* 🌳 Decision Trees & Ensemble Methods
* 🎯 Model evaluation & performance analysis
* 🔬 Practical ML experimentation
* 📉 Data visualization
* 🤖 Building and testing ML models

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
cd Machine-Learning-Lab
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Experiments

For Jupyter notebooks:

```bash
jupyter notebook
```

Open the required notebook from the `notebooks/` directory and run the cells sequentially.
